# SeatCanvas v1.0.0

**Release date:** 2026-06-11

First stable release of SeatCanvas — a cross-platform GPU-accelerated seat map library for ticketing and venue seating apps.

| Android | OpenGL ES | Sample app + CI |

| Web | WebGL 2.0 (WASM) | Sample (`web/demo`) + CI |
| macOS | Metal | Framework + headless tests |

### Core features

- SVG venue basemap parsing and GPU rendering
- Instanced seat drawing with dynamic style atlas (circle + SVG icons)
- Push-based seat state (pricecode, availability, selection) — no per-frame delegate style lookup
- Gestures: tap, pan, zoom with inertial scrolling and elastic edge bounce
- Zone interaction: tap, alternate minimap colors, zoom-to-zone
- Lifecycle callbacks: `didLoadBaseMap`, `didUnloadBaseMap`, `didUpdateZoomLevelConfig`

### Quality

- 25 unit test files + 24 Metal rendering snapshot scenarios
- GitHub Actions: build (iOS / Android / Web / OHOS) + autotest (macOS)

## Important notes for integrators

### Web fonts (required)

Web uses FreeType, not browser system fonts. You must load font files and register them **after** `SeatCanvasInit()` and **before** `app.init()`:

```typescript
const textFont = new Uint8Array(await (await fetch('/fonts/NotoSansSC-Regular.otf')).arrayBuffer());
SeatCanvasFont.registerFonts(textFont);
```

The npm package does **not** include font files.

### Basemap lifecycle

Always call `setDelegate` before `loadBaseMap`. Push styles and seat data in `didLoadBaseMap`:

```swift
// iOS example
seatCanvasView.delegate = self
seatCanvasView.loadBaseMap(svgData, format: .svg)
// didLoadBaseMap: registerPricecodes → applySeatStyleJSONConfig → setSeatData → updateSeatStatuses*
```

### Style keys

Use `SeatRenderStyleId.compose(pricecode, status, selected)` — same format as C++ `composeSeatStyleId`.

## Breaking changes (from early development)

If you tracked commits before 1.0.0:

- **Removed** delegate `styleIdForSeat` → use push APIs (`registerPricecodes`, `updateSeatStatusesForZone`, `setSelectedSeatIds`)
- **Removed** Web `registerFallbackFontNames` → use `SeatCanvasFont.registerFonts()`
- **Removed** zone highlight API and `SeatRenderMode`
- **Renamed** `rainbowColor` → `alternateColor` in zone JSON

## Known limitations

- Rendering snapshot tests run on **macOS Metal only** (GLES / WebGL not in CI).
- iOS exposes a temporary shader warmup API (planned to move into renderer startup).
- Zone name **Picture** rendering is on branch `experimental/zone-name-picture-ab-test` — not in 1.0.0.
